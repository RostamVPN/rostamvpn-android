# RostamVPN — store listing kit

Editable source for the App Store and Play listing art. The palette is read
from `brands/rostam.json`, so it is the app's own, not a copy that can drift.

Each panel is sized 1290x2796 by aspect-ratio, the App Store 6.9" shape; the
same markup renders the 6.5" and Play sizes.

**Store-text rule:** no provider, protocol, endpoint, IP or server count may
appear in any caption. A screenshot caption is public text, and Iran's NIN
reads public listings.
